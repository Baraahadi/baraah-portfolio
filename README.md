## ✦ About the Project

I wanted to build something more personal than a traditional portfolio.

This project takes visitors through an interactive, scroll-based experience, moving from early ideas and sketches to learning development tools and building real projects.

The focus is on combining frontend development with thoughtful animations and a visual story.

## 💻 Run Locally

Want to explore the code on your machine?

```bash
git clone https://github.com/Baraahadi/baraah-portfolio.git
cd baraah-portfolio
npm install
npm run dev
```

Once the development server starts, open the local URL shown in your terminal.
